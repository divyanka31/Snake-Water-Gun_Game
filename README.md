# Snake-Water-Gun Game

## About the Project
This is a simple command-line Snake-Water-Gun game developed using Python. The player competes against the computer, which randomly selects its choice.

## Technologies Used
- Python
- Random module
- Conditional statements
- Dictionaries

## How to Play
1. Run `main_game.py`.
2. Enter your choice:
   - `1` for Snake
   - `-1` for Water
   - `0` for Gun
3. The computer randomly selects its choice.
4. The program displays both choices and announces the result.

## How to Run
Make sure Python 3 is installed, then run:

```bash
python3 main_game.py
```
